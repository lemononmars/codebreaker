## 1. The Japanese Syllabary (`gojuon`)
- **Titles:** The Japanese Syllabary | ตารางห้าสิบเสียงญี่ปุ่น | 五十音図
- **Exercise Title:** พิกัดตารางโกะจูอง (Gojuon Coordinates)
- **Prompt:** ในตาราง 50 เสียงญี่ปุ่น แถว A (あ) มี あ, い, う, え, お ตัวอักษรที่อยู่ในแถว K (か) คอลัมน์ที่ 1 คือตัวอะไร? (เขียนเป็น Romaji 2 ตัวอักษร)
- **Image Description (What the image should look like):**
  - **Frame:** 520x240 dark indigo card.
  - **Visual Elements:**
    - ตาราง 5x2 แสดง 2 แถวแรกของตาราง 50 เสียง:
      - แถว 1 (A-dan): `[ あ (A) ]  [ い (I) ]  [ う (U) ]  [ え (E) ]  [ お (O) ]`
      - แถว 2 (K-dan): `[ ? ]  [ き (KI) ]  [ く (KU) ]  [ け (KE) ]  [ こ (KO) ]`
    - กล่องแรกของแถว K มีกรอบทองไฮไลท์และมีเครื่องหมาย [ ? ]
- **Solution Image Description:**
  - กล่อง [ ? ] สว่างขึ้นด้วยตัวอักษร 「**か**」 (KA) สีทอง
- **Hint:** สระเสียงแรกสุดของแถว K คือ Ka
- **Answer:** **KA**
- **Accepted Answers:** `["KA", "ka", "คะ", "กา", "か"]`
- **Explanation:**
  1. ตารางโกะจูองแถว K ประกอบด้วย: か (Ka), き (Ki), く (Ku), け (Ke), こ (Ko)
  2. ตัวแรกสุดที่ตรงกับสระ A คือ **KA** (か)
