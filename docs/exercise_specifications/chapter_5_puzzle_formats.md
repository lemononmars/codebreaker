## 1. Maze (`maze`)
- **Titles:** Maze | เขาวงกต | 迷路
- **Exercise Title:** ทางเดินเขาวงกตเก็บอักษร (Labyrinth Letter Path)
- **Prompt:** เดินจากจุด [START] ไปยังทางออก [GOAL] ผ่านเส้นทางที่ถูกต้องเพียงเส้นทางเดียว นำตัวอักษรที่เหยียบผ่านมารวมกันเป็นคำตอบ (ภาษาอังกฤษ 4 ตัวอักษร)
- **Image Description (What the image should look like):**
  - **Frame:** 520x240 dark slate card.
  - **Visual Elements:**
    - เขาวงกต 2 มิติขนาดกะทัดรัด (มีกำแพงสีน้ำเงินเข้ม #1e293b และเส้นทางเดินสีฟ้าอ่อน):
      - ทางเข้า [ START &bull; ธงเขียว ] ที่มุมซ้ายบน
      - ทางออก [ GOAL &bull; ธงทอง ] ที่มุมขวาล่าง
      - บนเส้นทางที่ถูกต้อง (ไม่ตัน) มีตัวอักษรวางอยู่ตามลำดับ: '**F**', '**I**', '**N**', '**D**'
      - บนเส้นทางที่ตัน (Dead ends) มีตัวอักษรหลอก: 'X', 'Z', 'Q'
- **Solution Image Description:**
  - เส้นทางเดินที่ถูกต้องเปล่งแสงสว่างสีเขียวมรกต ลากผ่านตัวอักษร F &rarr; I &rarr; N &rarr; D
  - ที่ด้านล่างสรุปคำตอบ: "**FIND**" (ค้นหา)
- **Hint:** เดินจาก START เลี้ยวขวา เจอกล่อง F, ลงล่างเจอกล่อง I, เลี้ยวขวาเจอกล่อง N, ลงสู่ทางออกเจอกล่อง D
- **Answer:** **FIND**
- **Accepted Answers:** `["FIND", "find", "ไฟนด์", "หา", "ค้นหา"]`
- **Explanation:**
  1. เส้นทางที่สามารถเดินผ่านจากจุด START ไปยัง GOAL โดยไม่ติดทางตัน
  2. จะเดินผ่านตัวอักษรตามลำดับคือ F, I, N, D
  3. รวมเป็นคำว่า **FIND** (ค้นหา)

## 2. One-Stroke Drawing (`one-stroke-drawing`)
- **Titles:** One-Stroke Drawing | ลากเส้นครั้งเดียว | 一筆書き
- **Exercise Title:** สะพานลากเส้นไม่ยกดินสอ (Eulerian Trail)
- **Prompt:** ลากเส้นผ่านทุกจุดโดยไม่ยกดินสอและไม่ทับเส้นเดิม รูปทรง "ซองจดหมายเปิดฝา" มีจุดยอด (Nodes) รวมทั้งหมดกี่จุด?
- **Image Description (What the image should look like):**
  - **Frame:** 520x240 dark slate card.
  - **Visual Elements:**
    - ภาพเรขาคณิตรูปซองจดหมายเปิดฝา (สี่เหลี่ยมด้านล่างที่มีกากบาทตรงกลาง และสามเหลี่ยมอยู่บนหลังคา)
    - แต่ละจุดมุมมีวงกลมสีทองเรืองแสงพร้อมตัวเลขกำกับ 1 ถึง 5:
      - มุมซ้ายล่าง (1), มุมขวาล่าง (2), มุมซ้ายบน (3), มุมขวาบน (4), ยอดสามเหลี่ยมบนสุด (5)
- **Solution Image Description:**
  - จุดทั้ง 5 สว่างวาบเป็นสีเขียวมรกตพร้อมตัวเลขขนาดใหญ่ตรงกลาง: "**5**"
- **Hint:** นับจุดมุมทั้งหมด: 4 มุมของสี่เหลี่ยม + 1 ยอดแหลมด้านบน
- **Answer:** **5**
- **Accepted Answers:** `["5", "ห้า", "FIVE", "five"]`
- **Explanation:**
  1. โครงสร้างกราฟรูปซองจดหมายเปิดฝามีจุดยอด (Vertices/Nodes) ทั้งหมด 5 จุด
  2. คำตอบคือ **5**

## 3. Crossword (`crossword`)
- **Titles:** Crossword | ปริศนาอักษรไขว้ | クロスワード
- **Exercise Title:** อักษรตัดกันในตารางไขว้ (Crossword Intersection)
- **Prompt:** คำแนวนอนคือ "CAT" (แมว) คำแนวตั้งคือ "CUP" (ถ้วย) ตัวอักษรที่อยู่ตรง "จุดตัดร่วมกัน" ที่ช่องแรกสุดคือตัวอะไร?
- **Image Description (What the image should look like):**
  - **Frame:** 520x240 dark slate card.
  - **Visual Elements:**
    - ตารางอักษรไขว้ขนาดเล็ก:
      - แนวนอน (1): `[ ? ]  [ A ]  [ T ]` (CAT)
      - แนวตั้ง (1): ช่องแรกตัวเดียวกับแนวนอน แล้วลากลงมา `[ U ]` และ `[ P ]` (CUP)
    - มีลูกศรสีทองชี้ไปที่ช่องมุมซ้ายบนที่เป็นจุดตัดร่วม
- **Solution Image Description:**
  - ช่องจุดตัดสว่างขึ้นด้วยตัวอักษรสีเขียวมรกต: "**C**"
- **Hint:** ตัวอักษรแรกสุดของคำว่า CAT และ CUP
- **Answer:** **C**
- **Accepted Answers:** `["C", "c", "ซี"]`
- **Explanation:**
  1. คำแนวนอน CAT ขึ้นต้นด้วยตัว **C**
  2. คำแนวตั้ง CUP ขึ้นต้นด้วยตัว **C**
  3. ตัวอักษรที่จุดตัดร่วมคือตัว **C**

## 4. Skeleton Crossword (`skeleton-crossword`)
- **Titles:** Skeleton Crossword | ครอสเวิร์ดโครงเปล่า | スケルトン
- **Exercise Title:** บรรจุคำลงโครงตาราง (Skeleton Grid Fit)
- **Prompt:** มีช่องแนวนอนว่างอยู่ 4 ช่องพอดี `[ _ ] [ _ ] [ _ ] [ _ ]` ในบรรดาคำต่อไปนี้: "CAT" (3), "BIRD" (4), "ELEPHANT" (8) คำใดสามารถนำมาใส่ลงในช่องได้พอดี?
- **Image Description (What the image should look like):**
  - **Frame:** 520x240 slate card.
  - **Visual Elements:**
    - โครงตารางสี่เหลี่ยมสีฟ้า 4 ช่องเรียงกัน
    - รายการคำศัพท์ 3 ตัวเลือกด้านข้าง:
      - `CAT` (3 letters)
      - `BIRD` (4 letters)
      - `ELEPHANT` (8 letters)
- **Solution Image Description:**
  - คำว่า "**BIRD**" เลื่อนเข้ามาบรรจุลงในช่องทั้ง 4 พอดีเป๊ะพร้อมไอคอนนกสีฟ้า
- **Hint:** นับจำนวนตัวอักษรที่เท่ากับ 4 ช่องพอดี
- **Answer:** **BIRD**
- **Accepted Answers:** `["BIRD", "bird", "เบิร์ด", "นก"]`
- **Explanation:**
  1. ช่องตารางมีจำนวน 4 ช่อง
  2. คำว่า BIRD มี 4 ตัวอักษร (B-I-R-D) จึงเป็นคำเดียวที่บรรจุได้พอดี

## 5. Polyominoes (`polyominoes`)
- **Titles:** Polyominoes | โพลิโอมิโน | ポリオミノ
- **Exercise Title:** ชิ้นส่วนเตตริสรูปตัวที (T-Tetromino Block)
- **Prompt:** ชิ้นส่วนเตตริสรูปตัว T (T-Tetromino) ประกอบด้วยสี่เหลี่ยมจัตุรัสเล็กๆ รวมกันทั้งหมดกี่ช่อง?
- **Image Description (What the image should look like):**
  - **Frame:** 520x240 dark arcade theme card.
  - **Visual Elements:**
    - ชิ้นส่วน Tetromino รูปตัว T สีม่วงสดใส:
      - แถวบน: สี่เหลี่ยม 3 ช่องเรียงกัน
      - แถวล่าง: สี่เหลี่ยม 1 ช่องยื่นลงมาตรงกลาง
    - คำถามกำกับ: `Total Squares = [ ? ]`
- **Solution Image Description:**
  - สี่เหลี่ยมทั้ง 4 ก้อนกระพริบสว่างพร้อมตัวเลข 1, 2, 3, 4 และผลรวม: "**4**"
- **Hint:** โพลิโอมิโนตระกูล "เตตระ" (Tetra) หมายถึงจำนวนเท่าใด?
- **Answer:** **4**
- **Accepted Answers:** `["4", "สี่", "FOUR", "four"]`
- **Explanation:**
  1. Tetromino ทั้งหมดเกิดจากการนำสี่เหลี่ยมจัตุรัส 4 ชิ้นมาต่อกัน
  2. แถวบน 3 ช่อง + แถวล่าง 1 ช่อง = **4** ช่อง

## 7. Wado Kaichin (`wado-kaichin`)
- **Titles:** Wado Kaichin | ปริศนาคันจิร่วมสี่ทิศ | 和同開珎
- **Exercise Title:** คันจิศูนย์กลางร่วมสี่ทิศ (Central Cross Kanji)
- **Prompt:** คันจิ 4 ตัวล้อมรอบวงกลมตรงกลาง: บน 「火」 (ไฟ), ล่าง 「水」 (น้ำ), ซ้าย 「木」 (ไม้), ขวา 「金」 (ทอง) คันจิตรงกลางที่รวมกับทั้ง 4 ตัวแล้วเป็นชื่อธาตุ/วันในสัปดาห์ได้คือ 「土」 (ดิน) ซึ่งภาษาอังกฤษแปลว่าอะไร? (4 ตัวอักษร: S _ _ L หรือ E _ _ _ H)
  *(ปรับให้กระชับมากยิ่งขึ้น:)*
  คันจิ 「日」 (SUN/วัน) สามารถนำไปต่อท้ายคำว่า 火, 水, 木, 金 กลายเป็น 火日, 水日... ตัวอักษรภาษาอังกฤษที่แปลว่า "ดวงอาทิตย์/วัน" คือคำว่าอะไร? (3 ตัวอักษร)
- **Image Description (What the image should look like):**
  - **Frame:** 520x240 dark slate oriental coin card (ทรงเหรียญโบราณวาโดไคชิน).
  - **Visual Elements:**
    - เหรียญโบราณทรงกลม มีช่องสี่เหลี่ยมตรงกลางที่มีเครื่องหมาย [ ? ]
    - 4 ทิศรอบเหรียญมีคันจิ 4 ตัว:
      - ทิศเหนือ: **火**
      - ทิศใต้: **水**
      - ทิศตะวันตก: **木**
      - ทิศตะวันออก: **金**
    - คำตอบตรงกลางคือคำว่า "SUN"
- **Solution Image Description:**
  - ช่องตรงกลางเหรียญสว่างขึ้นด้วยตัวอักษรสีทอง: "**SUN**"
- **Hint:** พระอาทิตย์ ภาษาอังกฤษ 3 ตัวอักษร สะกด S-U-N
- **Answer:** **SUN**
- **Accepted Answers:** `["SUN", "sun", "ซัน", "พระอาทิตย์"]`
- **Explanation:**
  1. ปริศนาแนว Wado Kaichin ใช้คันจิร่วมตรงกลางเพื่อประกอบกับคันจิ 4 ทิศ
  2. ธาตุสุริยะที่เป็นศูนย์กลางคือ **SUN**

## 8. Amidakuji (`amidakuji`)
- **Titles:** Amidakuji | บันไดสุ่มญี่ปุ่น | あみだくじ
- **Exercise Title:** บันไดลิงนำทาง (Ghost Leg Ladder)
- **Prompt:** ไต่บันไดสุ่มญี่ปุ่น (เดินลงล่าง เมื่อเจอสะพานแนวนอนต้องเลี้ยวข้ามเสมอ) จากจุดเริ่มต้น [ A ] จะเดินไปถึงปลายทางหมายเลขใด? (1, 2, หรือ 3)
- **Image Description (What the image should look like):**
  - **Frame:** 520x240 slate card.
  - **Visual Elements:**
    - เส้นแนวตั้ง 3 เส้น: หัวเสาด้านบนคือ [ A ], [ B ], [ C ]
    - ปลายเสาด้านล่างคือ [ 1 ], [ 2 ], [ 3 ]
    - สะพานแนวนอน 2 เส้น:
      - สะพานที่ 1 (ระดับบน): เชื่อมระหว่างเสา A และ เสา B
      - สะพานที่ 2 (ระดับล่าง): เชื่อมระหว่างเสา B และ เสา C
- **Solution Image Description:**
  - เส้นทางการเดินจาก [ A ] สว่างเป็นสีส้มทอง:
    - เริ่มที่ A &rarr; เดินลง &rarr; เจอสะพาน 1 เลี้ยวไปเสา B &rarr; เดินลง &rarr; เจอสะพาน 2 เลี้ยวไปเสา C &rarr; เดินลงถึงปลายทาง [ **3** ]
- **Hint:** จาก A ลงมาเจอเส้นขวางแรก ให้เลี้ยวไปเส้นกลาง แล้วลงต่อเจอเส้นขวางสอง ให้เลี้ยวไปเส้นขวาสุด
- **Answer:** **3**
- **Accepted Answers:** `["3", "สาม", "THREE", "three"]`
- **Explanation:**
  1. กฎของ Amidakuji: เดินตรงลงมา เมื่อพบเส้นเชื่อมขวางต้องเลี้ยวข้ามไปเสาข้างเคียงทันที
  2. จากจุด A เดินลงมาข้ามสะพานแรกไปยังเสา B
  3. เดินลงต่อมาข้ามสะพานที่สองไปยังเสา C
  4. เดินลงต่อไปจนถึงปลายทางที่หมายเลข **3**

## 14. Magic Square (`magic-square`)
- **Titles:** Magic Square | จัตุรัสกล | 魔方陣
- **Exercise Title:** จัตุรัสกล 3x3 (Lo Shu Magic Square)
- **Prompt:** จัตุรัสกล 3x3 ตัวเลข 1 ถึง 9 ในทุกแถว ทุกหลัก และเส้นทแยงมุมจะบวกกันได้ 15 เสมอ ตัวเลขตรงกึ่งกลางคือตัวเลขใด?
- **Image Description (What the image should look like):**
  - **Frame:** 520x240 dark slate mystical card.
  - **Visual Elements:**
    - ตาราง 3x3 บรรจุตัวเลขของจัตุรัสกลลั่วซู (Lo Shu):
      - แถว 1: `[ 4 ]  [ 9 ]  [ 2 ]` (รวมได้ 15)
      - แถว 2: `[ 3 ]  [ ? ]  [ 7 ]` (3 + ? + 7 = 15)
      - แถว 3: `[ 8 ]  [ 1 ]  [ 6 ]` (รวมได้ 15)
    - ช่องกึ่งกลางมีกรอบทองไฮไลท์พร้อมเครื่องหมาย [ ? ]
- **Solution Image Description:**
  - ช่องกลางสว่างจ้าด้วยตัวเลขสีทอง: "**5**" พร้อมผลรวมทุกทิศทาง 15
- **Hint:** แถวกลางมี 3 กับ 7 (รวมได้ 10) ต้องบวกอีกเท่าไรจึงจะได้ 15?
- **Answer:** **5**
- **Accepted Answers:** `["5", "ห้า", "FIVE", "five"]`
- **Explanation:**
  1. ในจัตุรัสกลขนาด 3x3 ผลรวมของทุกแถวและทุกคอลัมน์คือ 15
  2. แถวกลาง: 3 + [?] + 7 = 15
  3. 15 - 10 = **5** (ตัวเลขกึ่งกลางของจัตุรัสกล 3x3 คือ 5 เสมอ)
