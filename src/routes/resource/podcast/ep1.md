## 💡 สรุปภาพรวมประจำตอน

ใน EP.1 นี้ สองผู้ดำเนินรายการ **คุณซูม** และ **คุณเฟิร์ส** พาไปเจาะลึกคำว่า "เกมไขปริศนา" ที่คนส่วนใหญ่มักนึกถึงเพียงการต่อจิ๊กซอว์ แต่แท้จริงแล้วขอบเขตของเกมไขปริศนาครอบคลุมทั้ง **Puzzle**, **Riddle**, **Nazo-toki (謎解き)**, **RPG Puzzle** ไปจนถึง **บอร์ดเกมไขรหัส** สมัยใหม่

- **Puzzle**: การแก้โจทย์เชิงกลไก Pattern Matching หรือการวางแผน เช่น [Tetris](https://tetris.com) และ [Candy Crush](https://www.king.com/game/candycrush)
- **Riddle**: ปริศนาคำทาย ปัญหาเชาว์ที่เล่นกับภาษา เช่น ปริศนากลอนในภาพยนตร์ [Escape Room (2019)](https://www.imdb.com/title/tt6920084/)
- **Nazo-toki (謎解き)**: ปริศนาสไตล์ญี่ปุ่นที่ผสมผสานอักษรคันจิ ตรรกะ และความคิดสร้างสรรค์
- **RPG Mini-Games**: มินิเกมไขปริศนาในเกมฟอร์มยักษ์ เช่น [The Legend of Zelda](https://www.nintendo.com/store/products/the-legend-of-zelda-ocarina-of-time-3d-3ds/) และ [Life is Strange](https://store.steampowered.com/app/319630/Life_is_Strange__Episode_1/)
- **Standalone & Board Games**: เกมปริศนาเฉพาะทางอย่าง [Professor Layton](https://level5-global.com/layton/) หรือบอร์ดเกม [Exit: The Game](https://boardgamegeek.com/boardgamefamily/36963/series-exit-game-kosmos) และ [Unlock!](https://boardgamegeek.com/boardgame/213477/unlock-escape-adventures)

## 📊 ตารางสรุปประเภทและคำศัพท์เกมปริศนา

| ประเภท / คำศัพท์ | คำอธิบายและลักษณะเฉพาะ | ตัวอย่างเกม / ภาพยนตร์ / สถานที่ |
| :--- | :--- | :--- |
| **Puzzle** | เน้นการต่อชิ้นส่วน การจับคู่ การหารูปแบบ (Pattern) และการวางแผนแก้โจทย์เชิงกลไก | Jigsaw, [Tetris](https://tetris.com), [Candy Crush](https://www.king.com/game/candycrush), แอป IQ Test |
| **Riddle** | ปริศนาคำทาย ปัญหาเชาว์ คำกลอน หรือโจทย์ถาม-ตอบที่ใช้ภาษาเป็นหลักในการซ่อนคำตอบ | คำทายภาษา (เช่น แม่-ลูก), ปริศนาในภาพยนตร์ [Escape Room (2019)](https://www.imdb.com/title/tt6920084/) |
| **Nazo-toki (謎解き)** | เกมไขปริศนาสไตล์ญี่ปุ่น เล่นกับตัวอักษรคันจิ ภาษา ตรรกะเฉพาะตัว และ Puzzle Event | ปริศนาภาษาญี่ปุ่นบน YouTube, คอนเทนต์ Nazo-toki โดย [SCRAP Japan](https://www.scrapmagazine.com) |
| **RPG Puzzle / Mini-games** | ปริศนาที่แทรกในเกมหลัก เพื่อปลดล็อกดันเจี้ยน ปลดด่าน หรือดำเนินเนื้อเรื่องต่อ | [The Legend of Zelda](https://www.nintendo.com/store/products/the-legend-of-zelda-ocarina-of-time-3d-3ds/), Pokémon, [Life is Strange](https://store.steampowered.com/app/319630/Life_is_Strange__Episode_1/) |
| **Standalone & Board Game Puzzles** | เกมไขปริศนาเฉพาะตัวหรือบอร์ดเกมแก้รหัสแบบทำลายอุปกรณ์ หรือเล่นผ่านแอปมือถือ | [Professor Layton](https://level5-global.com/layton/), [Exit: The Game](https://boardgamegeek.com/boardgamefamily/36963/series-exit-game-kosmos), [Unlock!](https://boardgamegeek.com/boardgame/213477/unlock-escape-adventures) |
